# Coding Standards Review

## Objective

Verify that the change follows project coding standards and local engineering rules.

## Required reference

Reviewers must read and apply `../../engineering/GlobalRules.md` before completing this perspective.

## Review checks

- Check whether the change follows the rules in `../../engineering/GlobalRules.md`.
- Check whether the change follows file-local conventions and existing project patterns.
- Check naming, error handling, comments, formatting, test organization, and API readability.
- Check whether new scripts or reusable checks should be placed under `dev_harness/engineering/`.
- Check whether deviations from standards are explicit, justified, and bounded.

## Finding format

- Rule or convention affected.
- Evidence from changed files.
- Required correction.
- Whether a reusable rule should be added to `dev_harness/engineering/GlobalRules.md`.
