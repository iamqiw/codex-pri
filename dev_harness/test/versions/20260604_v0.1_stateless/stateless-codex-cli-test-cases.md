# Codex CLI 无状态服务测试用例

## 1. 测试范围

本测试用例集覆盖 `20260604_v0.1_stateless` 首版技术方案中可独立验证的协议、状态机、租约、幂等和只读 Runtime 行为。当前阶段实现 cloud wrapper 协议契约，并以 app-server v2 experimental `request/*` RPC 暴露最小分发面。

## 2. 首批 TDD 垂直切片

| --- | --- | --- | --- |
